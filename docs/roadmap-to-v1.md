# 路线图：从现有原型到 v1.0

本页根据原始 v0.1 technical note、原计划差距审计及各版实测报告整理。
v0.6–v0.9 是补齐原计划缺口的后续工程安排；不是把所有新安排当作最初就承诺过的里程碑。
版本号代表交付范围，不能代替基准、能耗或算法新颖性的证据。

| 阶段 | 已交付 | 仍欠缺 |

## v1.0 前的工作顺序

**2026-10-07 优先级调整（用户指定）**：以证明真实性能收益与完成 SNB Interactive v1
完整工作负载为主线。暂缓额外的能耗仪表、故障参数微调和微型 COUNT 校准；这些仍保留在
最终验收中。性能结论必须由实测支持，不能把“希望加速”作为既定结果。

当前实施顺序：完整模式导入 → 官方参考结果验证全部 29 种操作 → 精确查询优化与
构建/更新维护成本 → 相同输入的混合工作负载比较 → 更大规模/重复/正式时长 →
自适应近似方法与精确基线的同条件比较。完整精确 SNB 与允许误差的研究扩展分别报告。

**2026-10-08 主线调整（用户授权）**：优先检验算法本身的测量效率：少量真实评估学习
档位成本/误差 → 与随机搜索和普通 NSGA-II 同预算比较 → 独立穷举参照与留出检验 →
加入独立误差修正和不确定性校准 → 跨查询/图规模及全成本消融。完整精确 LDBC 保留为
验证基础；不再以精确 IC14 优化代替自适应算法证据。见 [v0.13 实验](v013-budgeted-search.md)。

用户进一步明确：用当前估计的可信程度决定样本量。v0.14 已实现低档试探、经验不确定性
驱动的升档、独立拟合/校准与消融。后续首先降低重复扫描与训练摊销成本，再把经过验证的
置信度门控接回预算搜索；机器压力不自动放宽答案误差要求。见 [动态实验](v014-dynamic-sampling.md)。

v0.15 按用户指定的速度—精度取舍，加入 5%/10%/20% 档位、校准热启动、历史复用与增量
统计。短流在线加速与长流训练/准备摊销分开报告。当前仍是静态图与已知谓词，后续需要
非重复参数查询、更多独立样本/规模、更新失效检测和策略消融。见 [速度—精度报告](v015-dlss-history.md)。

以下为其余验收要求，编号不表示本轮优先顺序。

v0.16 已完成 50k/100k 的独立校准与六个新样本轮次消融。较简单的校准热启动方案
在线比值为 1.70×/2.53×，预算违例为 0/720、9/720；不能把经验门控写成精度保证。
历史/增量没有稳定优势，因此保留为可选研究机制。公开仓库和 CV 文案已就绪，
完整研究验收仍按下列条件进行。见 [消融报告](v016-ablation-publication.md)。

1. **可靠性与成本**：量化抽查间隔的误差/检测延迟/成本，减少无需执行的全量恢复。
   先保留明确的故障类型和恢复前精确复核，再考虑自动调度；不能把盲区错误隐藏掉。
2. **能耗仪表**：检查此机器可读取的实际能量计数器或外部功率仪。
   明确 CPU package、数据库进程或整机的边界、采样/空闲基线、计数器回绕与背景负载。
   若硬件不可读，输出 unavailable 并记录原因；不得用延迟乘假定功率冒充测量。
3. **性能—能耗—精度目标**：只有取得可信 joules/request 后，才将能耗加入 NSGA-II。
   对相同工作负载、预算和准备成本比较 exact、固定档、穷举、NSGA-II 与自适应。
   报告独立重复和不利结果，区分离线优化、查询、构建、审计与恢复。
4. **标准工作负载与覆盖**：导入并核对 LDBC SNB 的数据/查询语义，先明确哪些 COUNT
   能采用现有估计器。多跳路径不能直接套用边 COUNT 的 `1/f²`。
   增加谓词稀疏度、故障发生相位、档位预算及图拓扑/规模的留出实验。
   未执行完整协议就标记“LDBC 子集/自定义工作负载”，不称合规基准。
5. **统一研究报告**：写清问题、算法/伪代码、系统边界、实验设计、基线、消融、
   全成本、失败情况、适用条件和复现步骤；用可核对的相关工作评估创新点。
   同步整理诚实的简历项目描述与演示。当前没有机器人或具身智能实验。

## v1.0 发布条件

- 原始实验保留，关键结果能从公开代码及私有原始记录复现。
- 图指纹、样本/拟合/校准/计时种子、测量边界和统计独立单位可追溯。
- 真实能耗测量存在，或醒目标注该验收项未完成；不能写成已实现能耗优化。
- 标准基准范围明确，精度保证与周期抽查的区别明确，跨图/更新能力不过度宣称。
- 测试、离线回退和 CI 通过；报告同时呈现成本上升、预算超限与失败情况。

本页会随实测更新。完整能耗、LDBC 和研究报告不能仅靠将版本号改成 1.0 完成。

含训练计时成本门控及独立确认。在线收益较小，短流计入准备仍更慢；不是零样本拓扑迁移。
